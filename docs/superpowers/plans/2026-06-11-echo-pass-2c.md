# Echo Pass 2c — Home Hero + Voice Rebuild + Intake Retirement

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Complete the Echo redesign: Home leads with an Echo hero input, the Voice page becomes a read-mostly WBTW dashboard, and the four legacy intake surfaces are hidden — all behind the existing admin gate so the founder reviews it in production before flipping for everyone.

**Architecture:** A single gate hook `useEchoExperience()` (returns `user?.isAdmin` today; the eventual flip-for-everyone is a one-line change here) controls all of 2c. When on: Home's resting create UI becomes the Echo hero, the docked pill is suppressed on Home (the hero is the input there), the Voice page hides its intake/chat widgets, and the legacy intake components stop rendering. When off (all current non-admin users): everything renders exactly as today. The generation/upload pipeline and Echo's param-handoff (`?echoPrompt` / `?echoFile`) are UNCHANGED — Echo still routes into them; 2c only retires the redundant *intake surfaces*, never the generation pipeline.

**Tech stack:** Next.js App Router, `useAuth`, `usePathname`, existing `useEcho` / `useEchoMic` / `EchoExchange` (reused, not rewritten), the app-canvas design tokens.

**Decisions (locked):** Build behind admin gate, flip later. Hide intake widgets via conditional render, keep their code one release for rollback (do NOT delete files).

**Constraints:** Do not modify `src/lib/api-client.ts`, auth, admin, billing. No copy changes to surviving copy; new Echo-hero/voice copy has no em dashes. Keep the live docked pill (`EchoPill.tsx`) working — non-admins and non-Home admin pages are unaffected.
