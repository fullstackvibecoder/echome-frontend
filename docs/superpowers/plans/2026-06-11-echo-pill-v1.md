# Echo Pill v1 (Pass 2b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Echo copilot pill — the universal intake — ships docked on every authenticated page, behind an admin-only gate, classifying input via `POST /api/echo/classify` and handing off to existing flows. No page rebuilds (Home/Voice rebuilds are Pass 2c).

**Architecture:** New `src/components/echo/` component family mounted once in `AppShell` (inside `.app-canvas`), rendered only when `user.isAdmin`. A new `src/lib/echo-client.ts` module wraps the classify endpoint using the exported `apiClient` axios instance — `src/lib/api-client.ts` is NOT modified (CLAUDE.md sensitive path). Intent handoffs: create → navigate to `/app?echoPrompt=…` (Create page seeds its text input); ingest → `api.kbContent.paste`; question → `api.kb.chat` against the default KB; command → client-side navigation map. Exchanges are capped (intent chip → optional clarify → handoff + mono receipt); outputs never render in-thread.

**Tech Stack:** Next.js App Router, Tailwind v4 with the existing app-canvas tokens (`.text-machine`, `--dur-*`, `--ease-standard`), Waveform primitive (`src/components/ui/waveform.tsx`), exported `apiClient` axios instance, `useAuth` for the admin gate, `useVoiceContext`/`api.kb.list()` for the default KB id.

**Spec:** `docs/superpowers/specs/2026-06-10-platform-redesign-echo-copilot-design.md` (Echo anatomy, exchange rules, receipts, cyan discipline). Staging backend already serves `/api/echo/classify` (echome-platform-v2 PR #103).

**Constraints:**
- DO NOT modify: `src/lib/api-client.ts`, `src/app/auth/`, `src/app/app/admin/`, billing components.
- Existing copy untouched. New Echo strings: no em dashes. Placeholder: `Tell Echo anything...` (three dots, not ellipsis char). Receipts uppercase mono via `.text-machine`.
- Waveform appears in the pill (it is a voice moment: Echo listening). Cyan: pill focus glow + intent chip only.
- The admin gate is `user.isAdmin` — no new flag infrastructure in v1.

### Task 1: Echo client module

**Files:**
- Create: `src/lib/echo-client.ts`

- [ ] **Step 1: Create the module** (read `src/lib/api-client.ts` lines 40-60 first for the `apiClient` export and response conventions; adjust the response unwrap to the backend's `ApiResponse` shape `{ success, data, timestamp }`):

```ts
// src/lib/echo-client.ts
/**
 * Echo copilot client (v1). Lives outside api-client.ts deliberately:
 * api-client.ts is a protected path (CLAUDE.md); this module consumes its
 * exported axios instance, which already carries JWT sync + interceptors.
 */
import { apiClient } from './api-client';

export type EchoIntent = 'create' | 'ingest' | 'question' | 'command';

export interface EchoClassification {
  intent: EchoIntent;
  confidence: number;
  args: Record<string, string>;
  source: 'llm' | 'heuristic';
  latencyMs: number;
}

export interface EchoContext {
  page?: string;
  itemId?: string;
  hasAttachment?: boolean;
}

export async function classifyEchoInput(
  text: string,
  context?: EchoContext,
): Promise<EchoClassification> {
  const response = await apiClient.post('/echo/classify', { text, context });
  return response.data.data as EchoClassification;
}
```

**Behavioral contract (from spec):**
1. **Docked state:** fixed pill, bottom-center of the main content area (not overlapping the sidebar: `left: 50%` within the content column is acceptable v1), `rounded-full`, surface `bg-surface-container-low border border-border`, Waveform (static) at left, placeholder text `Tell Echo anything...` in `text-muted-foreground`, `⌘K` hint chip in mono at right. Cyan glow ONLY on focus/expanded (`--shadow-glow-cyan`).
2. **Summon:** click or Cmd+K / Ctrl+K opens the expanded state and focuses the input. Escape collapses. Clicking outside collapses (unless mid-exchange request).
3. **Expanded state:** the exchange container opens UPWARD from the pill (absolute positioned panel, max-height ~50vh, overflow-y-auto): a real text input (textarea, autosize up to 4 rows, Enter submits, Shift+Enter newline).
4. **Submit flow:** input → `classifyEchoInput(text, { page })` → render the INTENT CHIP (mono uppercase: `CREATING A KIT`, `ADDING TO YOUR VOICE`, `QUESTION`, `COMMAND`) with the four alternatives selectable (chip row lets the user correct the intent with one click) + a confirm affordance. Low confidence (<0.6) requires explicit confirm; high confidence auto-executes after rendering the chip for ~600ms unless the user intervenes — v1 SIMPLIFICATION: always require one click on the chip/confirm button. No silent execution.
5. **Execution per intent** (in `useEcho.ts`):
   - `create` → `router/navigate('/app?echoPrompt=' + encodeURIComponent(args.prompt ?? text))`, collapse pill, receipt `HANDED TO CREATE`.
   - `ingest` → `api.kbContent.paste({ text: args.note ?? text, sourceType: 'text', title: 'Echo note' })` → receipt `ADDED TO YOUR VOICE · TEXT NOTE`. On failure: inline error in the exchange (reuse `getErrorMessage` from `src/lib/error-utils.ts`).
   - `question` → resolve default KB id once (lazy: `api.kb.list()` → `is_default` or first; cache in module state) → `api.kb.chat(kbId, args.query ?? text)` → render the ANSWER inside the exchange as a single quiet block (this is a conversational response, allowed; it is not a content output) + receipt `ANSWERED FROM YOUR VOICE`.
   - `command` → map `args.target` to routes: library→`/app/library`, calendar→`/app/calendar`, settings→`/app/settings`, voice→`/app/voice`, radar→`/app/radar`, kit→`/app/library`; navigate + collapse + receipt `OPENED <TARGET>`.
6. **Receipts:** last line of every completed exchange, `.text-machine`, e.g. `ADDED TO YOUR VOICE · 14:32`. Keep a transient list (this session only, max 3 visible); no persistence in v1.
7. **Reduced motion:** no breathing animation when `prefers-reduced-motion` (Waveform handles this already); expansion uses `--dur-base`/`--ease-standard` transition.
8. **A11y:** pill is a `button` with `aria-label="Open Echo"`; expanded container `role="dialog"` `aria-label="Echo"`; focus trapped while open; Escape closes; intent chips are buttons.

`intent-meta.ts` centralizes per-intent labels/receipt verbs so EchoExchange stays presentational.
